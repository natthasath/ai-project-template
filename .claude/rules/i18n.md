# Internationalization (i18n) Rules

## สถานะปัจจุบัน

**Phase 0–6:** App ใช้ภาษาไทยเป็นหลัก — ยังไม่ implement i18n จริง
**Phase 7+:** เพิ่ม `react-i18next` เมื่อถึง phase นั้น (อยู่ใน pre-approved dependencies)

Rule นี้กำหนดมาตรฐานที่ต้องทำตาม **ตั้งแต่ตอนนี้** เพื่อให้ refactor ไป i18n ในอนาคตง่ายขึ้น

---

## กฎที่บังคับตั้งแต่ Phase 0

### ห้าม Hardcode Text ใน Components

```typescript
// ❌ ห้าม — hardcode text ใน JSX
function TimerControls() {
  return (
    <button>เริ่ม</button>
  )
}

// ✅ ถูก — ใช้ constant จาก locale file
import { UI_TEXT } from '@shared/constants/ui-text'

function TimerControls() {
  return (
    <button>{UI_TEXT.timer.start}</button>
  )
}
```

### การใช้ `useTranslation`

```typescript
// ✅ ระบุ namespace ชัดเจน
import { useTranslation } from 'react-i18next'

function TimerControls() {
  const { t } = useTranslation('timer')
  return <button>{t('start-button')}</button>
}

// ✅ Pluralization
const { t } = useTranslation('tasks')
t('pomodoro-count', { count: 3 })   // "3 โพโมโดโร"

// ✅ Interpolation
t('session-duration', { minutes: 25 })  // "25 นาที"
```

## Thai-specific Rules

### ตัวเลข

```typescript
// ✅ ใช้ Intl.NumberFormat สำหรับ format ตัวเลข
const formatter = new Intl.NumberFormat('th-TH')
formatter.format(1234)   // "1,234"

// ✅ Timer display — ใช้ 2-digit เสมอ (ไม่ขึ้นกับ locale)
function formatTime(seconds: number): string {
  const m = Math.floor(seconds / 60).toString().padStart(2, '0')
  const s = (seconds % 60).toString().padStart(2, '0')
  return `${m}:${s}`     // "25:00" — ไม่ใช้ Intl เพราะ format ตายตัว
}
```

### วันที่และเวลา

```typescript
// ✅ ใช้ Intl.DateTimeFormat แทน manual format
const date = new Intl.DateTimeFormat('th-TH', {
  dateStyle: 'medium',
  timeStyle: 'short',
}).format(new Date())
// "29 พ.ค. 2569, 14:30"

// ❌ ห้าม manual format วันที่
const date = `${d.getDate()}/${d.getMonth() + 1}/${d.getFullYear()}`
```

### ภาษาไทยใน aria-label

```typescript
// ✅ aria-label เป็นภาษาไทย (ช่วย screen reader ภาษาไทย)
<button aria-label="เริ่มจับเวลา">
  <PlayIcon />
</button>

// ✅ เมื่อ implement i18n
<button aria-label={t('timer.start-aria-label')}>
  <PlayIcon />
</button>
```

## Font Support

ถ้าต้องการรองรับทั้ง Thai และ English ใช้ font ที่รองรับทั้งสองภาษา:

```css
/* ✅ Font stack ที่รองรับ Thai */
font-family: 'Sarabun', 'Noto Sans Thai', 'Prompt', system-ui, sans-serif;

/* ✅ ถ้า load Google Fonts */
/* @import ใน CSS หรือ <link> ใน index.html */
/* ต้องมี font-display: swap เสมอ */
```

## สิ่งที่ห้าม

- ❌ Hardcode text ใน JSX โดยไม่ผ่าน constant หรือ translation key
- ❌ Mix ภาษาใน key เดียวกัน เช่น `t('เริ่ม timer')`
- ❌ ใช้ Google Translate API หรือ external translation service — ทุก text ต้องมีใน locale files
- ❌ Hardcode locale เป็น `'th-TH'` ในหลายๆ ที่ — ให้ centralize ที่ `src/shared/config/locale.ts`
