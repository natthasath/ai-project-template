## Task ID Format

`TSK-{PHASE}-{NUMBER}` เช่น `TSK-0-001`, `TSK-1-003`

## Task Template

```markdown
### TSK-X-XXX — ชื่อ task

**Phase:** X  
**Priority:** High / Medium / Low  
**Estimate:** X Pomodoros  
**Status:** Backlog / In Progress / Done / Blocked  
**Blocked by:** (ถ้ามี)

**Description:**
อธิบายสิ่งที่ต้องทำ

**Acceptance Criteria:**
- [ ] criteria 1
- [ ] criteria 2

**Notes:**
หมายเหตุเพิ่มเติม (ถ้ามี)
```

## Priority Legend

- **High** — บล็อก phase progress, ต้องทำก่อน
- **Medium** — ต้องทำในช่วง phase นี้ แต่ไม่บล็อกอะไร
- **Low** — nice-to-have, ย้ายไป phase ถัดไปได้ถ้าจำเป็น
